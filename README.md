# GlobalLead AI

A mobile-first, evidence-first client and opportunity intelligence platform.

## Module 01 — Foundation & UI/UX

This repository now uses a maintainable multi-file React + TypeScript + Vite architecture. The current module includes:
- Responsive application shell and mobile navigation
- Dark/light theme toggle
- Dashboard and search-preference setup
- Reusable page structure and honest empty states
- A visible 10-module implementation roadmap

Search submission currently validates and acknowledges the selected preferences only. It does **not** claim to fetch leads. Live data discovery is introduced in Modules 03–06.

## Stack
- React 18 + TypeScript + Vite
- Lucide React icons
- CSS design tokens and responsive layouts
- Vercel deployment target
